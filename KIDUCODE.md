# KiduCode Roadmap

## Planned Features

- Manglish prompt preprocessing
- Malayalam/Manglish explanation mode
- Kerala-focused developer templates
- Local-first provider configuration
- Team and enterprise-ready deployment options

## Manglish Mode Concept

KiduCode will eventually support prompts such as:

```text
oru login page undakku
ee bug fix cheyyu
backend il jwt auth add cheyyu
button click cheythal modal open aavanam
```

The goal is to let developers express intent naturally in Manglish or Malayalam while KiduCode converts that intent into precise coding-agent instructions.

## Independence

KiduCode is an independent fork of OpenCode. It is not affiliated with, endorsed by, or sponsored by the OpenCode team, Anomaly, or the original OpenCode maintainers.

## Upstream Merge Strategy

KiduCode should keep upstream OpenCode compatibility where practical. Branding and KiduCode-specific features should be isolated so upstream updates can be merged with minimal conflict.
